Smart FAQ Chatbot
A Smart FAQ Chatbot built using Python, Streamlit and Ollama LLM.

Features
Answers questions about college syllabus.
Uses an LLM to generate answers.
Simple and user-friendly interface.
Provides clear syllabus-related information.
Technologies Used
Python
Streamlit
Ollama
Llama 3.2
Project Files
app.py - Main Python application
syllabus.txt - Course syllabus
requirements.txt - Required libraries
Installation
Install the required packages:

pip install -r requirements.txt

Download the Ollama model:

ollama pull llama3.2

Run the Project
streamlit run app.py

Output
The chatbot answers questions related to the course syllabus
